# scalreg

Fits scaled sparse linear regression models.

Compatibility updates by Renova.

Adds structured author metadata and documents the usage of the sp500 data set.

## Installation

```r
install.packages("scalreg", repos = c(
  Renova = "https://renova-r.r-universe.dev",
  CRAN = "https://cloud.r-project.org"
))
```

Version `1.0.1.9001` is based on [CRAN 1.0.1](https://cran.r-project.org/package=scalreg).
